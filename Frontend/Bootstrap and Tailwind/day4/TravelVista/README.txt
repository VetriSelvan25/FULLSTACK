# TravelVista - Enhanced Travel Website

Built with:
- HTML5
- CSS3
- JavaScript

## Added in this version
- Real travel photography from Pexels
- Attractive full-screen hero background
- Gradient overlays and glassmorphism search box
- Smooth card hover animations
- Image zoom transitions
- Scroll reveal animations
- Floating hero shapes
- Mobile hamburger menu
- Dark/light mode
- Responsive layout
- Destination search
- Travel budget calculator
- FAQ accordion
- Contact form validation
- Travel gallery with 6 destinations

## Run
Open `index.html` in a browser, preferably with VS Code Live Server.

## Images
The project uses remote Pexels image URLs, so an internet connection is needed for photos.
See `images/IMAGE_SOURCES.txt` for the source pages and image information.

## Dynamic destination explorer
Click a destination photo, country/location label, or Explore button to open a detailed destination panel.
The panel contains:
- Large destination hero image
- Destination description
- Travel facts
- Six beautiful places to visit
- Clickable place photos
- Full-screen image viewer
- Previous/next photo controls
- Keyboard arrow navigation
- Escape-to-close
- "Plan This Trip" button that jumps to the contact form
