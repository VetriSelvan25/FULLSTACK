TASK 1 – EVEN OR ODD Create a function:
checkEvenOdd(number)
Pass one number as an argument.
If the number is divisible by 2:
→ Return "Even Number"
Otherwise:
→ Return "Odd Number"
Example:
checkEvenOdd(10)
Output:
Even Number
